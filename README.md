Inventory App
Briefly summarize the requirements and goals of the app you developed. What user needs was this app designed to address?
For this project I created an inventory app. I chose an inventory app because I used to work with one at my last job and already had an idea of how one should work. The goal of the app was to give the user a way to keep track of their inventory, including adding items and changing the amount of an item they have.
What screens and features were necessary to support user needs and produce a user-centered UI for the app?
The app needed a login screen, an inventory screen, and the ability to set up SMS notifications. The inventory screen needed to make it easy for the user to add and manage their items. I tried to keep the controls simple so the user could understand what they needed to do.
The UI itself was actually one of the parts I had trouble with while making the app. I was able to get it working, but if I had more time, one of the things I would change is making the UI look better.
How did you approach the process of coding your app? What techniques or strategies did you use?
I worked on the different parts of the app and tested them as I went. One of the biggest problems I ran into was that I would get one thing working and then something else wouldn't work. This meant I had to keep going back through my code to find out what changed and what was causing the new problem.
This taught me that when working on another app in the future, I need to test things as I make changes. Just because one feature is working doesn't mean that a change won't cause a problem somewhere else in the app.
How did you test to ensure your code was functional? Why is this process important, and what did it reveal?
I tested my app using the Android Emulator with the Galaxy Z Fold 10 Pro. I would run the app and test the different features to make sure they were working. This was important because there were times when I would fix one part of the app and find out that another part was no longer working.
Testing helped me find these problems and make changes until I could get the whole app working correctly.
Where did you have to innovate to overcome a challenge?
One of my biggest challenges was the UI itself. I had to make changes to get the different parts of the UI to work correctly with the rest of the app. There were also times when fixing one problem caused another problem, so I had to go back and figure out what was causing it.
Getting through these problems took a lot of testing and making changes until everything worked together.
In what specific component of your mobile app were you particularly successful?
I was happiest when I finally got the whole app working. There wasn't just one feature that stood out to me because getting all of the different parts to work together was the biggest accomplishment for me.
If I had more time to continue working on the app, I would make the UI look better, create a better icon for the app, and add a barcode scanner. I think a barcode scanner would be especially useful for an inventory app because it would make adding and finding inventory items easier.
